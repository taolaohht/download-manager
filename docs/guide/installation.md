# Installing Prism

Prism is released as a **Windows 10/11 x64 portable ZIP only**.

1. Download the ZIP from the [latest release](https://github.com/FortoGraphy/prism-download-manager/releases/latest).
2. Extract it to any folder, including a USB drive.
3. Run `prism.exe`.

No installer or administrator permission is required. Prism stores settings, history, tools,
and other app data in the `data` folder beside `prism.exe`.

After the first start, install the browser extension to let Prism catch downloads and videos:
[browser-extension.md](browser-extension.md).

## Updating

When Prism reports a new version, choose **Get the update** to open the download page. Download
the new portable ZIP and extract it over the existing folder after closing Prism. Keep the
existing `data` folder to preserve settings, history, and queues.

## Uninstalling

Close Prism and delete its folder. If you want to keep your data, copy the `data` folder
somewhere safe before deleting it.
